1 Introduction

In this practical, we will explore how to use a machine learning method known as a Support Vector Machine (SVM) to classify and predict outcomes from two different types of datasets.

SVMs are supervised learning models that became popular in the 1990s for their strong performance in pattern recognition and classification tasks. They are widely used in psychology, neuroscience, and education research to identify patterns in complex data and to make predictions based on those patterns.

In the first part of this session, we will use a dataset containing undergraduate performance data from 2013 and 2014. This dataset includes students’ first-year marks across five psychology modules and their final degree classifications. We will use these data to train an SVM model that predicts whether a student will receive a First Class degree based on their first year performance.

In the second part, we will use neuroimaging data collected by Haxby et al. (2001). These data measure activity in the fusiform face area (FFA) while a participant viewed images of faces, houses, and scrambled patterns. We will train an SVM classifier to distinguish between brain activity patterns associated with these different stimulus categories.

Learning Objectives

As a reminder, by the end of the week you should be able to:

  1. Explain how support vector machines construct decision boundaries for linear and non-linear data.
  2. Understand how the hyperparameters C and gamma control model complexity.
  3. Justify the use of train/test splits and cross-validation for model fitting and evaluation.
  4. Interpret different evaluation metrics across classification contexts.
  5. Fit, tune, and evaluate SVM classification models using the caret package in R.

3 Predicting degree classification

Read in the ARM8_data_UndergraduateOutcomes.csv file from your data/ folder.

undergrad_outcomes <- read.csv("./data/ARM8_data_UndergraduateOutcomes.csv")

The dataset contains student performance information from undergraduate cohorts in 2013 and 2014. For each student, the dataset includes:

  • Year: The year in which students completed their degree programme.
  • Award.mark: Their overall mark following degree completion.
  • Degree.class: The degree class for that mark (what we want to predict).
  • RM1: First-year marks from Research Methods I.
  • BB1: First-year marks from Brain and Behaviour I.
  • PC1: First-year marks from Perception and Cognition I.
  • LD1: First-year marks from Language and Development I.
  • SP1: First-year marks from Social Psychology and Individual Differences I.

This dataset will allow us to build and test an SVM model that predicts whether a student is awarded a First Class degree based on their first-year performance.

3.1 Formatting Data

Similar to what you did in Week 4: Mixed-effects modelling, we are going to factorise the Degree.class variable, but also ensure it only has two groups: First and Not First.

# Create new data frame with an added variable
undergrad_outcomes_cor <- dplyr::mutate(undergrad_outcomes,
  # New variable based on Degree.class
  degree_class = factor(
    # Label "1" as "First", others as "Not First"
    dplyr::case_when(
      Degree.class == "1" ~ "First",
      TRUE ~ "Not First"
    ),
    # Set order of factor levels
    levels = c("First", "Not First")
  )
)

Here we create a new version of the dataset, undergad_outcomes_cor, based on undergad_outcomes. We use the mutate() function to tell it to add a new variable, degree_class, which is a factor version of the existing Degree.class variable. Using case_when(), we recode the value “1” as “First” and everything else as “Not First”. By setting the factor levels, we are letting R know which variable will be in the predicted class.

3.2 Training the model: Degree class

Now that we have loaded the data and created our new degree_class variable, we can train our first SVM model. The goal is to predict whether a student will achieve a First Class degree or not, based on their marks in their five first-year modules. The formula interface allows us to specify the outcome variable (degree_class) and the predictors (the five module marks) in one step.

# Set a seed for reproducibility
set.seed(1503)

# Train a linear SVM model with 10-fold cross-validation
svmFit <- caret::train(
  degree_class ~ BB1 + PC1 + LD1 + SP1 + RM1, # Model formula
  data = undergrad_outcomes_cor, # Data
  method = "svmLinear", # Method
  trControl = caret::trainControl(method = "cv", # Cross-validation
                                  number = 10), # 10-folds
  preProcess = c("center", "scale") # Standardise variables
)

The code above calls the train function from the caret package to generate our SVM model. Using the formula interface, we specifically ask to predict degree outcome using each of the five module marks. We specify a linear SVM by setting method = "svmLinear". We use the trControl argument to apply 10-fold cross-validation; this means the data are split into 10 (approximately) equal parts, called folds. The model is trained on 9 of the folds and tested on the remaining fold. This process repeats 10 times so that every fold is used once for testing. The reported accuracy is the average across all 10 runs, which gives a more reliable estimate of how well the model performs on unseen data. Lastly, we use the preProcess argument to standardise the data. Although the module marks are already scaled, standardisation is included as a best practice, though it won’t affect the model outcome.

4 Predicting stimulus type from voxel response

In the second part of this practical, we’ll use fMRI data from a single participant in Haxby et al. (2001) to investigate whether the fusiform face area shows preferential responses to faces. Make sure you have ARM8_data_Haxbyetal2001.csv data downloaded from the VLE and stored in your /data folder.

Exercise 3

Repeat the process of loading in data as you did for the undergraduate outcomes. The file is called ARM8_data_Haxbyetal2001.csv. Load this dataset into R and assign it to a dataframe named haxby.

Show solution 
haxby <- readr::read_csv(file = "./data/ARM8_data_Haxbyetal2001.csv")

The dataset contains voxel-level responses from the fusiform face area (FFA) recorded while the participant viewed different types of visual stimuli. The variables are:

  • Condition: The type of stimulus presented on each trial. This can be Face, House, or Scrambled. This is the variable we will attempt to predict.
  • Trial: The trial number for the presentation of the stimulus. Each stimulus type has trials numbered from 1 to 12.
  • Vox_*: All remaining columns represent the activation levels of individual voxels within the FFA during each stimulus presentation. Each column corresponds to one voxel.

4.1 Training the model: Face vs. scrambled images

In this part, we will train an SVM to classify Face versus Scrambled images using a hold-out validation approach. Instead of training the model on the entire dataset, we will split the data into a training set and a test set. The model is fitted using the training set and then evaluated on the test set to assess how well it generalises to new data. This method provides an independent check on model performance and is particularly useful when sample sizes are small, as cross-validation can become unstable with limited data. In such cases, a simple train-test split offers a clean and practical way to estimate predictive accuracy.

4.1.1 Data preparation

Before we can fit the model, however, we need to do a little data preparation!

# Conditions of interest
con_int <- c("Face", "Scrambled")

# Keep only Face and Scrambled trials
haxby_fs <- dplyr::filter(haxby, Condition %in% con_int)

# Make Condition a factor
haxby_fs <- dplyr::mutate(haxby_fs,
                          Condition = factor(Condition, levels = con_int)
)

# Remove the Trial column
haxby_fs <- dplyr::select(haxby_fs, !Trial)

# Select the first 6 trials from each condition for training
train_data_fs <- dplyr::slice_head(
  dplyr::group_by(haxby_fs, Condition),
  n = 6
)

# Remove grouping so later functions don't get confused
train_data_fs <- dplyr::ungroup(train_data_fs)

# Use the remaining trials as the test set
test_data_fs <- dplyr::anti_join(haxby_fs, train_data_fs)

In the above, we first selected the conditions of interest, keeping only the Face and Scrambled trials from the dataset. We then converted the Condition variable into a factor so that R treats it as a categorical variable with a defined order. The Trial column was removed because it is not needed for model training. Next, we grouped the data by condition and used slice_head() to take the first six trials from each group as the training set. After ungrouping, we used anti_join() to create the test set containing the remaining trials. This process ensures that the model is trained and tested on separate data.

4.1.2 Fitting the model

Now that we have the data prepared, we can fit the model and then test how well it fits to unseen data!

# For reproducibility
set.seed(1503)

# Train a linear SVM model
svmFit <- caret::train(
  Condition ~ ., # Model formula: . = Use all variables in dataframe
  data = train_data_fs, # Data
  method = "svmLinear", # Method,
  preProcess = c("center", "scale") # Standardise variables
)

The code above generates the SVM model. Once the model has been created, we can evaluate how well it performs on unseen data using the test_data dataset and the confusionMatrix function from caret. If your code is correct, you should see output similar to the example below.

# Predict and evaluate
preds_fs <- stats::predict(svmFit, 
                           newdata = test_data_fs)

conf_matrix_fs <- caret::confusionMatrix(preds_fs, test_data_fs$Condition)

Looking at the confusion matrix, it appears the model is performing better on the unseen data than it did on the seen data. Specifically, it is correctly categorising trials 92% of the time, only getting one face stimulus incorrect. The higher accuracy on the test data could be due to chance rather than genuine generalisability. If the training set contains more variability or noisier examples than the test set, the model may appear to perform unusually well when evaluated. This happens because the training and test splits are small, so random differences in which trials fall into each set can strongly influence performance. In other words, the model’s success here probably reflects sample variability rather than a true ability to generalise to new data.

As shown in the confusion matrix, the model does not perform as well as in the original Face vs. Scrambled comparison. The accuracy is 67%, which is only slightly higher than the no information rate of 50% (and not significant, p = .194), indicating limited improvement over chance. Overall, the model captures some structure in the data but struggles to distinguish the two categories reliably, being biased more towards classifying a trial as a House than a Face. 6 Summary

Congratulations, you have now trained and evaluated SVM models in R using the caret package! Once the data are properly formatted, the same workflow can be applied to a range of datasets with minimal adjustments. In this session, you used SVMs to classify both behavioural and neuroimaging data, applying cross-validation and hold-out validation to assess performance and explore the effects of sample composition. You also learned to interpret confusion matrices by examining accuracy, sensitivity, specificity, and comparisons with the no information rate. Further, you learned to assess feature importance to understand which variables most strongly influenced model decisions.
