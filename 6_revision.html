1.3 Fictional context

Today’s dataset is simulated for the purpose of demonstrating the different analytic choices you might experience for any one project. Imagine that you are part of a university research team investigating student wellbeing. Your central question is: What helps students cope with stress, sleep better, and perform well academically?

From your reading, you find that previous studies seem to disagree about which interventions work. You suspect that individual students might respond differently to interventions, and that the average effect may conceal important differences.

4 Part B

Your own university has already collected some data from a pilot intervention called RESET. 526 students signed up for the programme from across 12 different courses, and 378 completed it. Measures of stress and were recorded at each time point (self-ratings from 0-100), and an additional measure of sleep quality was collected at the end.

Load and inspect the data (ARM6_trialdat.csv). You should see that it is in long format: each participant has one row per assessment point (two rows in total).

Q4: Test whether there was a change in stress levels between the two time points (i.e., before and after the intervention). Choose a model that can handle the repeated measurements for each student, and retain participants with missing data in the analysis. You want to additionally account for the fact that students on different courses may have experienced different academic challenges during this period, and might experience difference changes in stress.

  1. What type of model should you use, and how should the model be specified?
  2. What was the average self-rated stress score before the intervention, and how did it change between the two time points?
  3. Which course showed the least change in stress levels over time?

The lmer() function requires a formula for your fixed effects, plus (+) random effects specified as (1|grouping) for intercepts or (1+predictor|grouping) for slopes.

In the practical, we plotted random effects with the following code dotplot.ranef.mer(ranef(model)).

# Load data
trial_dat <- read.csv("data/ARM6_trialdat.csv")

# Run model
change_mod <- lmer(stress ~ time + (1+time|student_id) + (1+time|course),
                   data = trial_dat)

# Print output
summary(change_mod)

# Explore random effects
dotplot.ranef.mer(ranef(change_mod))

# Fit ordinary least squares regression model

# Inspect output

You can fit more than one quantile at once using tau = c(x, x, x), replacing the x values with your chosen quantiles. You can inspect the results further using plot(summary(model)) and the anova() functions.

Q7: You are also interested in understanding more about the people who did versus did not complete the intervention (i.e., those who were missing data at the second time point). You have a hypothesis that the students who dropped out of the intervention had more timetabled hours per week. Run a t-test to test this hypothesis, and then calculate bootstrapped 95% confidence intervals to provide more robust estimates of the t-statistic in the context of a mild skew.

  1. What does the main t-test show?
  2. Do the bootstrapped confidence intervals support the same conclusions?

  • Show hint

Note, the best option is to resample the two groups independently so that ensure that enough participants in each group are sampled for each analysis.

Some example code to extract relevant observations from the completed group would be filter(trial_dat, completed == 1) %>% pull(timetabled_hours). You should save the output to a new object, and then edit to do the same for the non-completed group.

Once you have your two variables to sample, you will need to:

  1. Create a variable to store the t-statistics from your resampled t-tests.
  2. Set up a loop that runs e.g., 1000 times
  3. Within the loop: (1) resample each of your groups; (2) run a new t-test; and (3) save the t-statistics to the relevant part of your list.
  4. Use the quantile() function with c(0.025, 0.975) to calculate 95% confidence intervals.
# Run t-test
t.test(timetabled_hours ~ completed, data = trial_dat)

# Split dataset into two groups, and extract the relevant variable for ease of resampling
comp_group <- filter(trial_dat, completed == 1) %>% 
  pull(timetabled_hours)

notcomp_group <- filter(trial_dat, completed == 0) %>% 
  pull(timetabled_hours)

# Set up vector to store t-statistics for each resampled t-test
all_t <- NULL

# Bootstrap
for (i in 1:1000){ 
  
  # Resample each dataset
  resample_comp <- sample(comp_group, replace = TRUE)
  resample_notcomp <- sample(notcomp_group, replace = TRUE)
  
  # Run new t-test
  new_test <- t.test(resample_comp, resample_notcomp)
  
  # Save t-statistic to list
  all_t[i] <- new_test$statistic
}

# Calculate 95% confidence intervals
quantile(all_t, c(0.025, 0.975))
